# تصميم «طلباتي»

تم تطبيق ترتيب الصورة المرجعية «طلباتي 2.webp» باستخدام ألوان الثيم الأزرق المعتمد، في الوضعين الفاتح والداكن.

- عنوان الصفحة هو العنصر الأبرز، دون بطاقة الإحصاءات القديمة.
- «تقديم عذر» زر بعرض الصفحة بالذهبي المعتمد، مع تعطيله عند غياب نشاط يمكن ربط العذر به.
- تبويبان متساويان للأعذار والاعتراضات، مع العدد الإجمالي لكل قسم. الفلاتر لا تغيّر العدد الإجمالي.
- فلاتر الحالة أصغر وأهدأ: الكل، قيد الانتظار، مقبول، مرفوض. يشمل الانتظار الحالات المحالة للمشرف.
- بطاقات مختصرة: أيقونة، اسم الطلب، تاريخه، وشارة الحالة. فتح البطاقة يعرض التفاصيل والإجراءات الحالية.
- يظهر زر «اعترض على القرار» داخل العذر المرفوض فقط عندما يسمح الباك إند بالاعتراض. لا يظهر في الطلبات المقبولة أو قيد المراجعة، أو بعد انتهاء المهلة أو وجود اعتراض سابق.
- التبرعات والمبالغ وسجل الإثباتات داخل قائمة ⋮، بدل ازدحام أعلى الصفحة.
- لا تُعرض الأرقام الحمراء أو الشروحات الجانبية الموجودة في الصورة المرجعية داخل التطبيق.

لم تتغير قواعد القبول أو المراجعة أو مهلة الاعتراض في الباك إند. شاشة سجل الإثباتات تحتفظ بتدفقها الحالي، والتصميم الجديد مخصص لـ «طلباتي».

الاختبارات: ٣١ اختبار واجهة ناجحًا، ومنها الأعداد والفلاتر والقائمة وفتح الاعتراض وعدم إتاحته للطلب غير المستحق، والعرض الضيق مع تكبير الخط. عند ضيق الشاشة تنتقل شارة الحالة لسطر مستقل بدل التداخل مع اسم الطلب.
