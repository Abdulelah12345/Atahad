# قرارات العمل الحالية

- **ميزة القراءة الخارجية/ربط الكتب: ملغاة بطلب المستخدم.** لا تُستكمل أو تُدرج ضمن المهام القادمة.
- **لعبة درب الخير ودمجها بالتطبيق: ملغيان بطلب المستخدم.** تبقى الملفات السابقة أرشيفًا محليًا؛ لا يُستكمل تطويرها أو دمجها.
- **ميزة إدخال التعهّد بالمايكروفون:** مؤجلة للنقاش؛ لم تُنفّذ ضمن هذه التعديلات.
- **تعهّد المشي:** نُفّذ الباك إند والواجهة والربط البرمجي؛ الاختبار على أجهزة فعلية ما زال مطلوبًا قبل النشر.
- **طلباتي:** طُبّق مرجع «طلباتي 2» بالأزرق والكحلي والذهبي مع الوضعين الفاتح والداكن.
- **عنوان نموذج العذر:** «وضّح سبب تعذّرك» بدل «ظروفك لها اعتبار».
- **الكويز:** تطبيق البرومبت العام الرسمي المعتمد؛ كل سؤال داخل نطاق الموضوع وخياراته منطقية. يظهر خيار تجهيز الأسئلة بدون صور قبل إنشاء الاختبار، حتى مع وجود صور أو بعد تعذّر تحليلها. لا يعاد إنشاء اختبار صالح لمجرد تبديل المصدر.

إلغاء ميزة القراءة الخارجية لا يلغي الكويز الموجود أو إمكانية استخدامه مع الأنشطة التعليمية.
